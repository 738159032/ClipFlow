# PRD · 商品 3D 展示与短视频制作工具

> 状态：阶段 0（工程初始化 + 关键技术验证）。本文档只描述**已确认**的目标与范围，未实现的能力统一标注。

## 1. 产品目标

让电商运营/设计师在浏览器里完成"商品 3D 展示 → 加图文信息 → 导出竖屏短视频"的全流程，不需要 3D 软件、不需要剪辑软件。

核心价值：

1. **一次建模，多场景复用**：上传 GLB，自动居中定框，切换模板即可产出不同风格的展示视频。
2. **所见即所得**：预览与导出共享同一套场景配置、动画时间轴和 2D 光栅器，导出结果与预览一致。
3. **纯前端出片**：WebCodecs 本地编码 MP4，不上传商品素材到服务端。

## 2. 目标用户与核心流程

**用户**：中小电商运营、品牌视觉设计师、代运营服务商。

**主流程（MVP）**

1. 打开工作台 → 选择画幅（竖屏 9:16 / 方形 1:1 / 横屏 16:9）。
2. 上传商品 GLB（或使用内置示例模型）。
3. 选择模板（极简影棚 / 日落新品 / 暗调金属）→ 自动套用材质、灯光、动画、相机。
4. 微调：材质参数、灯光强度、模型缩放与旋转、动画时长。
5. 编辑 2D 图层：标题文字、价格标签、水印。
6. 预览播放，检查构图与节奏。
7. 导出 MP4（固定分辨率/帧率/时长）→ 下载。

**异常流程**：模型加载失败 → 场景保留错误态并提示原因，可继续编辑其他部分；导出失败 → 显示编码器诊断信息，不生成假文件。

## 3. MVP 范围

### 3.1 阶段 0（本次交付：验证 + 骨架）

| 能力 | 范围 |
|---|---|
| 工程基线 | Next.js App Router + TS + lint + typecheck + vitest + Playwright + build |
| 3D 预览 | 客户端 Canvas、WebGL 探测、错误边界 |
| 模型 | 单个 GLB 加载、自动居中/统一尺寸、材质覆盖、dispose |
| 相机 | 配置驱动初始机位 + OrbitControls 手动查看 |
| 灯光/材质 | 各 4 套预设 + 参数调节 |
| 动画 | 4 个预设（转台/悬浮/入场/静止），时长可调，预览与导出共用采样函数 |
| 2D 图层 | 文字 / 价格标签 / 水印，归一化坐标，Canvas2D 光栅化 |
| 合成 | 3D 帧 + 2D 图层 → 单帧 Canvas（PNG 静帧可下载） |
| 导出 | WebCodecs H.264 + mp4-muxer，固定 1080×1920@30fps、5s，进度/取消/失败诊断 |
| 文档 | AGENTS / PRD / ARCHITECTURE / DECISIONS / TASKS / ACCEPTANCE |

### 3.2 明确不在阶段 0 范围

- 图片素材上传与贴图替换（仅 GLB）——**未实现**。
- 多图层直接拖拽/缩放/旋转手柄（当前通过属性面板数值编辑）——**未实现**。
- 关键帧时间轴、曲线编辑——**未实现**，当前只提供参数化预设动画。
- 音频轨道、字幕轨、多场景拼接——**未实现**。
- 项目持久化（localStorage / 云端工程）——**未实现**，刷新即重置。
- 服务端渲染/转码、账号体系、支付——**未实现**。
- 移动端适配（导出依赖 WebCodecs H.264，移动端 Safari 能力待验证）——**未验证**。

## 4. 成功指标（阶段 0 判定）

- 一台装有桌面版 Chrome 的机器上，`npm run verify` 与 `npm run test:e2e` 全绿。
- 导出的 MP4 能被 `<video>` 正常播放，且分辨率、帧率、时长与设置一致。
- 导出画面中 2D 文字位置与预览一致（同一光栅器保证，e2e 抽帧比对）。
